# Solo Operator v0.1.0

Initial public release of an evidence-first Codex skill for one-person businesses.

## Included

- Operator Ladder, Evidence Ladder, One-Person Test, and Build Gate.
- Actionable, bounded experiments and explicit opportunity verdicts.
- Optional project context: current state and decisions when present, a useful
  first step when no project files exist.
- Codex interface metadata with automatic selection enabled.
- English documentation, installation instructions for Windows/macOS/Linux,
  examples, contribution guidance, and MIT licensing included in the skill package.
- GitHub Actions package validation on Windows and Linux.
- Eight synthetic behavioral cases with a no-skill control and all 16 raw answers.

## Evidence and limits

Both baseline and skill-enabled responses passed all eight scenarios under the
predeclared qualitative rubric. The baseline was already strong. The report
records useful differences and remaining weaknesses, including idea-list sprawl
and incomplete experiment thresholds. It does not claim statistical superiority.

See the [full behavioral report](https://github.com/beukkung/solo-operator/blob/v0.1.0/evals/REPORT.md) and
[package workflow](https://github.com/beukkung/solo-operator/actions/workflows/validate.yml).
Model evaluations were run through Codex CLI 0.154.0, requesting `gpt-6-astra` with
medium reasoning effort. The scoring is unblinded AI review, not human validation.

## Install

```text
Use $skill-installer to install the skill from
https://github.com/beukkung/solo-operator/tree/v0.1.0/skills/solo-operator
```

The skill has no runtime dependency beyond Codex. Python and PyYAML are used only
to develop and validate this repository. Model evaluations consume Codex quota
and do not run automatically in CI.
